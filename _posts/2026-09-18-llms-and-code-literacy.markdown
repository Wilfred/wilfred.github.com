I'm increasingly using LLMs to help me write code, but I'm reading
more code than ever.

I think code literacy, the ability to read source code and comprehend
software, remains critical.

This blog post is a worked example to try to persuade you. Rather than
an AI hype piece, I have all my prompts.

The reports of coding's death seem greatly exaggerated.
